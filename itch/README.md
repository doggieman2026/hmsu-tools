# itch.io アップロードのしかた（hmsu Games 13本）

## 最初の1回だけ
1. https://itch.io/register で登録（メールとパスワード）。届いたメールのリンクを押して確認。
2. 右上のメニュー →「Upload new project」。

## 1本ごと（2〜3分）
1. **Title**：下の表の英語タイトル
2. **Kind of project**：`HTML`
3. **Uploads**：`○○.zip` を選ぶ → 出てくる「This file will be played in the browser」にチェック
4. **Embed options**：`Mobile friendly` にチェック、`Fullscreen button` にチェック、サイズは 480 × 800（横長のゲームは 960 × 600）
5. **Short description**：下の表の説明文を貼る
6. **Cover image**：`○○-cover.png`
7. **Genre / Tags**：表のとおり
8. **Pricing**：`No payments`（あとで投げ銭にしたくなったら `Donate` に変更）
9. 一番下の **Visibility** を `Public` →「Save」
